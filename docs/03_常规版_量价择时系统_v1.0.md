# 常规量价模拟盘 · 机制设计 v1.1

> 定位：把打板模拟盘里已经跑通的**门控 → 选股 → 持有 → 卖出 → 推送**骨架，换成一套以
> **择时和量价**为核心的常规波段系统。
>
> 它不追涨停，不做连板接力；它只做三件事：
> **在横盘/深坑里等、在连续小涨启动时买、在人声鼎沸/连续大涨/放量急跌时卖。**
>
> v1.1 变更（2026-11-12）：冰点期只放行“深坑”，最多 1 只、风险预算 0.5x；不再一刀切禁止所有新仓。
>
> 参数标准表：[`config/regular_v1.yaml`](../config/regular_v1.yaml)
> 参数手册：[`docs/04_常规版_参数手册.md`](04_常规版_参数手册.md)
> 模拟盘代码：[`deploy/regular_paper/`](../deploy/regular_paper/)

## 0. 一句话与三条硬约束

**一句话：** 先用市场温度决定“能不能做、做多重”，再用横/坑/小涨决定“买什么”，
最后用放量、加速、上影线决定“什么时候走”。

三条硬约束，和打板盘一致：

| 约束 | 内容 | 为什么 |
|---|---|---|
| **T 日收盘出计划，T+1 开盘执行** | 不做盘中追单，不用未来数据 | 日线级模拟盘唯一可复现的执行方式 |
| **每层只能更严，不能更松** | 门控否决的票，选股不能救回来 | 防止“看到好票就破例” |
| **参数只从 YAML 读** | 代码不写死阈值，改参数不改代码 | 方便按市场情绪/个人研究迭代，也能追溯 |

## 1. 八条口诀 → 八条可执行规则

| 口诀 | 量化翻译 | 落地层 | 主要参数 |
|---|---|---|---|
| **买横买坑，不买竖** | 20 日箱体振幅 ≤12%、5/20 量比 ≤0.9 才叫横；10 日高点回撤 12%–35%、下跌无量才叫坑；5 日涨 ≥12% / 离 MA20 ≥10% / 3 日内 2 根大阳，一律不买 | 选股 + 买入 | `selection.platform_*`、`selection.pit_*`、`selection.vertical_*` |
| **卖在人声鼎沸处** | 市场温度 ≥75 或指数偏离 MA20 ≥8% / 20 日涨 ≥15% → 停止开仓、仓位上限压到 40%；极端温度 ≥85 → 盈利仓减半 | 门控 + 卖出 | `timing.hot_*`、`timing.market_climax_heat`、`timing.cap_hot` |
| **连续小涨要大涨** | 5 日内 ≥3 天单日涨 0.2%–3%、累计 2%–10%、收盘在当日上半段、量比 0.6–2.0 → 启动候选 | 选股 | `selection.small_rise_*` |
| **连续大涨要离场** | 最近 N 日 ≥3 根 ≥4% 大阳，或 5 日累计 ≥15% → 减半；≥22% 或 4 根大阳 → 清仓 | 持有/卖出 | `holding.climax_*` |
| **急跌无量是洗盘** | 持仓单日 ≤-3% 但量比 ≤0.7、仍在 MA60 上方且 MA60 不向下 → 不卖，标记“洗盘持有” | 持有 | `holding.washout_*` |
| **急跌放量立马撤** | 持仓单日 ≤-4% 且量比 ≥1.5 → 清仓；指数急跌且放量 → 市场 CRASH，总仓位 0 | 卖出 + 门控 | `exit.volume_dump_*`、`timing.crash_*` |
| **快速冲高要回落** | 日线代理：最高价 ≥昨收+5%、收盘 ≤昨收+1%、上影线 ≥3%、量比 ≥1.5、未封涨停 → 减半 | 卖出 | `exit.failed_spike_*`、`exit.upper_shadow` |
| **不挖深坑不大买** | 只有坑深 ≥25%、趋势未坏（收盘 > MA60 且 MA60 不向下）才把单笔风险预算放大到 1.25 倍；没有深坑不许大买 | 选股 + 仓位 | `selection.deep_pit_depth`、`entry.size_mult_deep_pit` |

> **关于“快速冲高要回落”的诚实说明：** 原文说的是“开盘半小时猛拉不封板”，需要分时数据。
> 本系统是日线级，用“长上影 + 放量 + 收盘回落 + 未封板”做代理。它抓不到 9:45 前的诱多，
> 但能在收盘后确认“今天冲高失败”，并在次日开盘/收盘处理。**这是代理，不是等价物。**

## 2. 总架构：和打板盘同骨架，换引擎

```
全市场快照
   ↓
L0 可交易性：剔除 ST/北交所/低价/低流动性/停牌
   ↓
L1 择时门控：市场温度 → COLD/REPAIR/TREND/HOT/CRASH → 总仓位上限 + 允许形态
   ↓
L2 选股：横 / 坑 / 深坑 / 连续小涨 + “不买竖”否决
   ↓
L3 评分：趋势 30 + 结构 30 + 量能 25 + 触发 15 → 候选排序
   ↓
L4 买入：T+1 开盘条件单（gap 区间 + 止损价 + 目标仓位）
   ↓
L7 组合：槽位、单票上限、组合风险预算、熔断
   ↓
L5 持有：NORMAL / WASHOUT / CLIMAX / BREAK
   ↓
L6 卖出：硬止损 → 放量急跌 → 无量洗盘 → 趋势走坏 → 人声鼎沸/连续大涨
          → 冲高回落 → 移动止盈 → 时间止损
   ↓
L8 日报/盘前推送 + 逐笔归因
```

与打板盘最大的不同：

| | 打板盘 | 常规版 |
|---|---|---|
| 票池 | 涨停池/炸板池/连板 | 全市场流动性前 N |
| 买点 | 打板/接力/首板 | 横盘、坑反转、连续小涨 |
| 持有 | 2–3 日 | 10–20 日，趋势不破不走 |
| 仓位 | 固定权重为主 | **风险预算 ÷ 止损距离** |
| 卖出 | 固定 TP/SL + 加速态 | 量价状态 + 移动止盈 |
| 主题 | 主线题材 | 不强制主线，行业只做分散约束 |

## 3. L1 门控：市场温度与五状态

### 3.1 温度公式

五个分项都压到 0–1，再按权重合成 0–100：

```
Trend    = 0.45·I(C>MA20) + 0.30·I(C>MA60) + 0.15·I(MA20>MA60)
           + 0.10·clip((MA60斜率 + 1%) / 3%)
Breadth  = clip((MA20上方家数占比 - 20%) / 60%)
Momentum = clip((指数20日收益 + 3%) / 15%)
Volume   = clip((指数成交额/20日均值 - 0.75) / 0.75)
Up       = clip((上涨家数占比 - 30%) / 50%)

Heat = 100 × (0.30·Trend + 0.25·Breadth + 0.20·Momentum + 0.15·Volume + 0.10·Up)
```

> 宽度用已扫描的流动性股票池近似全市场；这是**样本宽度**，不是全市场宽度。
> 参数表里没有把它伪装成精确值，报告会写 `n=...`。

### 3.2 五状态

| 状态 | 进入条件（优先级从上到下） | 总仓位上限 | 允许新开仓形态 | 动作 |
|---|---|---|---|---|
| **CRASH 急跌** | 指数单日 ≤-3%；或 5 日 ≤-6% 且量比 ≥1.2；或指数在 MA60 下方、MA60 下压且宽度 <35% | 0% | 无 | 清仓 |
| **HOT 过热** | 温度 ≥75；或偏离 MA20 ≥8%；或 20 日 ≥15%；或宽度 ≥80% 且量比 ≥1.5 | 40%（极端 30%） | 无 | 停止开仓；盈利仓减半 |
| **TREND 趋势** | 温度 ≥55 且指数在 MA20 上方、MA20 上翘、MA60 不向下 | 90% | 横、横+小涨、坑、深坑、小涨 | 正常做 |
| **REPAIR 修复** | 温度 ≥30 或指数在 MA20 上方，但趋势条件不满足 | 50% | 横、横+小涨、坑、深坑 | 只做有结构的，不做纯小涨 |
| **COLD 冰点** | 其余 | 20% | 仅深坑（默认最多 1 只、风险 0.5x） | 深坑小仓试错；横盘/小涨不做 |

**迟滞与驻留：** 过热/趋势/修复有 ±5 温度迟滞；除 CRASH/HOT 外，状态至少驻留 2 日。
目的不是“预测”，而是防止温度在阈值附近来回跳，导致今天满仓明天空仓。

**冰点深坑例外：** 冰点期默认只允许 `DEEP_PIT`，不允许横盘/小涨。原因是
“不挖深坑不大买”本身就把深坑定义为一个买点；一刀切禁止会和口诀冲突。
但例外有硬约束：`cold_max_positions=1`、`cap_cold=20%`、`size_mult_cold_deep_pit=0.5`，
且仍要求个股在 MA60 上方、MA60 不向下、下跌无量、重新站上 MA5。它只解决“深坑也不让买”
的结构矛盾，不解决“没有深坑”的问题。

### 3.3 “急跌无量是洗盘”在市场层的例外

如果指数单日 ≤-2%、量比 ≤0.8、仍在 MA60 上方且 MA60 不向下：

- **不切 CRASH**；
- 状态仍按温度归类，但报告标记 `washout=True`；
- 持仓不因为“指数跌了”而恐慌清仓，仍按个股的硬止损/趋势破位执行。

这条例外的优先级高于“指数单日跌幅”触发，但**不高于个股硬止损**。

### 3.4 “卖在人声鼎沸处”怎么落地

不是一过热就全卖，而是三层：

1. **门控层：** HOT 停止开新仓，仓位上限从 90% 压到 40%；
2. **极端层：** 温度 ≥85 或宽度 ≥85% + 放量 + 偏离 MA20，`market_climax=True`，盈利仓减半；
3. **个股层：** 连续大阳/5 日大涨/长上影放量，按 L6 减半或清仓。

这样既不会在过热初期卖飞，也不会在真正的人声鼎沸里满仓。

## 4. L2/L3 选股：横、坑、深坑、小涨

### 4.1 股票池

| 过滤 | 默认 | 说明 |
|---|---|---|
| 价格 | ≥2 元 | 面值/仙股尾部风险 |
| 流通市值 | ≥30 亿 | 承接与流动性 |
| 20 日平均成交额 | ≥1 亿 | 量价判断可靠、滑点可控 |
| 扫描数 | 成交额前 300 | 首次拉取 2–5 分钟，之后走缓存 |
| 历史长度 | ≥120 日 | 同时算 MA60、60 日高点、20 日箱体 |
| 排除 | ST、北交所、当日涨停、停牌 | 制度/不可交易 |

### 4.2 四种形态

#### A. 横盘 `PLATFORM`

```
20 日箱体振幅 = 最高/最低 - 1 ≤ 12%
收盘在箱体内（上下沿 ±2% 容差）
5 日均量 / 20 日均量 ≤ 0.90          # 缩量
MA20 斜率 ≥ -0.2%                    # 走平或上翘
收盘 ≥ MA60 × (1 - 2%)               # 长期趋势不坏
```

**为什么是“买横”而不是“买突破”：** 突破当天往往已经“竖”了，次日开盘再买就是追高。
本系统在箱体里等，用次日开盘 gap 控制成本；突破后反而不买。

#### B. 坑反转 `PIT_REVERSAL`

```
最近 10 日“高点→低点”跌幅在 -12% ~ -35%
下跌日平均量 / 20 日均量 ≤ 0.90      # 无量急跌 → 洗盘
收盘重新站上 MA5
收盘 ≥ 昨收 × 0.99 且收阳
收盘 > MA60 且 MA60 斜率 ≥ -0.1%     # 趋势未坏
```

#### C. 深坑 `DEEP_PIT`

在 B 的基础上，坑深 ≥25%。只有这个形态允许把单笔风险预算放大到 **1.25 倍**。
这就是“不挖深坑不大买”的量化：**没挖坑，不给大仓位。**

#### D. 连续小涨 `SMALL_RISE`

```
最近 5 日 ≥3 天单日涨幅在 0.2%–3.0%
5 日累计 2%–10%
收盘 > MA20，离 MA20 ≤8%
量比 0.6–2.0                        # 温和放量，不是爆量
收盘位置 ≥50%                       # 收在当日上半段
```

横盘 + 小涨同时成立时，标记 `PLATFORM_SMALL_RISE`，风险预算 1.0 倍；
这是“横盘缩量后缓步推升”的最优组合。

### 4.3 “不买竖”的硬否决

任一命中即排除，且**不能靠评分救回来**：

| 否决 | 默认阈值 |
|---|---|
| 5 日涨幅 | ≥12% |
| 10 日涨幅 | ≥20% |
| 离 MA20 | ≥10% |
| 最近 3 日大阳线（≥4%） | ≥2 根 |
| 当日涨幅 ≥6% 且量比 ≥1.5 | 直接排除 |
| 当日放量急跌（≤-4% 且量比 ≥1.5） | 不接飞刀 |
| 长上影 ≥3% + 量比 ≥1.5 + 收盘涨幅 <3% | 不接诱多 |

### 4.4 评分

```
Score = 100 × (0.30·Trend + 0.30·Structure + 0.25·Volume + 0.15·Trigger) - Penalty
```

| 分项 | 主要看什么 |
|---|---|
| **Trend 30%** | 收盘 > MA20、MA20 > MA60、MA60 上翘、不偏离 MA20 太远 |
| **Structure 30%** | 横盘越紧越好；坑越深（在 12%–35% 内）越好 |
| **Volume 25%** | 横盘缩量、坑内下跌无量、小涨温和放量 |
| **Trigger 15%** | 小涨天数、站上 MA5、收盘位置 |
| **Penalty** | 长上影 + 放量 -8；当日涨 ≥6% -5 |

默认最低分 60。提高分数会减少交易，降低会引入噪声；不要为了“多几个信号”把它降到 40。

### 4.5 为什么不再做“主线题材”

打板盘需要主线，因为连板接力的收益来自题材扩散。常规波段赚的是**个股量价结构**的钱，
强行加“主线”会变成两个 beta 叠加：题材热 + 个股热，回撤也会叠加。

本版保留行业字段只做两件事：

1. 单日计划同行业最多 2 只；
2. 持仓同行业最多 2 只。

数据源没有行业时，行业记为“未分类”，这两条不生效——报告会明确写出来。

## 5. L4 买入：次日开盘条件单

### 5.1 条件单

T 日收盘生成，T+1 开盘判定：

```
开盘 gap = 开盘价 / 昨收 - 1

平台/小涨：  -2.5% ≤ gap ≤ +2.0%
坑/深坑：    -3.5% ≤ gap ≤ +2.0%
硬性追高线： gap > +4.0% → 任何形态都不买
一字/涨停开盘 → 买不进，跳过
开盘 ≤ 计划止损价 → 不买（开盘已破位）
```

不在区间就不成交，**不盘中改价、不追单**。

### 5.2 止损与仓位

```
止损价 = min( max(支撑位, 信号日收盘 × (1 - 7%)), 信号日收盘 × (1 - 3%) )
支撑位 = 平台下沿×0.99 / 坑底×0.99 / MA10×0.99
```

解释：止损优先放在结构支撑下方，但最大亏损不超过 7%，最小距离不小于 3%。
3% 是为了避免支撑太近被日内噪声扫掉。

仓位由风险预算反解，而不是拍一个固定百分比：

```
目标权重 = min( 单票上限 28%,
                单笔风险预算 1.25% × 形态倍数 / 止损距离 )
形态倍数：平台 0.90 / 坑 1.00 / 深坑 1.25 / 纯小涨 0.80 / 横+小涨 1.00
冰点深坑例外：深坑倍数降为 0.50，且总仓受 cap_cold=20%、最多 1 只约束
```

例：止损距离 7%，深坑 1.25 倍 → `1.25% × 1.25 / 7% ≈ 22.3%`，低于 28% 上限，取 22.3%。

组合层还有两道闸：

- 全部持仓的“入场价-止损价”风险之和 ≤ 净值的 5%；
- 状态总仓位上限（TREND 90% / REPAIR 50% / HOT 40% / CRASH 0%）。

### 5.3 T+1 与跌停

- 当日买入不可卖；
- 跌停封死（最高价 ≤ 跌停价）当日不可卖，顺延到下一个可成交日；
- 跌停打开后按打开价成交，不假设跌停价能卖出。

## 6. L5 持有：四种状态

每天收盘算一次，优先级从上到下：

| 状态 | 判定 | 处置 |
|---|---|---|
| **BREAK 走坏** | 收盘 < MA60；或连续 2 日收盘 < MA20 | 清仓 |
| **WASHOUT 洗盘** | 单日 ≤-3%、量比 ≤0.7、收盘 > MA60、MA60 不向下 | 不卖；标记“洗盘持有”；硬止损仍有效 |
| **CLIMAX 加速** | 最近 N 日 ≥3 根 ≥4% 大阳；或 5 日 ≥15%；或长上影+放量+当日涨 ≥3% | 减半；5 日 ≥22% 或 4 根大阳 → 清仓 |
| **NORMAL 正常** | 其余 | 持有；浮盈 ≥10% 后启动 8% 移动止盈 |

> WASHOUT 不是“无限扛”。它只豁免“放量急跌”和“情绪恐慌”，
> **不豁免硬止损，也不豁免跌破 MA60**。这就是“急跌无量是洗盘”与“趋势坏了也要走”的边界。

## 7. L6 卖出：优先级不可违反

| 优先级 | 规则 | 触发 | 动作 | 参数 |
|---:|---|---|---|---|
| 1 | 硬止损 | 开盘 ≤ 止损价 → 开盘价；盘中最低 ≤ 止损价 → 止损价 | 清仓 | `entry.stop_loss` |
| 2 | 市场急跌 | 状态 = CRASH | 清仓 | `timing.cap_crash` |
| 3 | 放量急跌 | 单日 ≤-4% 且量比 ≥1.5 | 清仓 | `exit.volume_dump_*` |
| 4 | 无量洗盘 | 单日 ≤-3%、量比 ≤0.7、仍在 MA60 上方、MA60 不向下 | **不卖** | `holding.washout_*` |
| 5 | 趋势走坏 | 收盘 < MA60；或连续 2 日 < MA20 | 清仓 | `holding.ma_trend`、`holding.below_ma_days` |
| 6 | 人声鼎沸 | 市场极端温度，且持仓盈利 | 减半 | `timing.market_climax_heat` |
| 7 | 连续大涨 | ≥3 根大阳 / 5 日 ≥15% | 减半；≥22% 或 4 根大阳清仓 | `holding.climax_*` |
| 8 | 冲高回落 | 高 ≥+5%、收 ≤+1%、上影 ≥3%、量比 ≥1.5、未封板 | 减半 | `exit.failed_spike_*` |
| 9 | 移动止盈 | 浮盈 ≥10% 后，从最高点回撤 8%；或浮盈后破 MA10 | 清仓 | `holding.trail_*` |
| 10 | 时间止损 | 持有 ≥15 日且收益 <3% | 清仓 | `holding.time_stop_*` |

**为什么硬止损永远第一：** 任何“洗盘”“人声鼎沸”“再等等”都不能覆盖 -7% 的硬止损。
这是整套系统唯一不需要解释的规则。

## 8. L7 组合：槽位、风险、熔断

| 项 | 默认 | 说明 |
|---|---|---|
| 槽位 | 4 | 常规波段持仓 10–20 日，4 个槽位比打板的 3 个更稳 |
| 单票上限 | 28% | 与风险预算共同约束 |
| 单笔风险 | 1.25% | 由止损距离反解仓位 |
| 组合风险上限 | 5% | 全部持仓未触发止损的风险之和 |
| 同行业上限 | 2 | 行业未知时不生效 |
| 日亏熔断 | -3% | 次日禁止开新仓 |
| 回撤减半 | 8% | 总仓位上限 ×0.5 |
| 回撤停止 | 12% | 停 5 个交易日，人工复核 |

**风险预算而不是固定仓位**，是本版和打板盘最大的风控差异：
同样是 20% 仓位，止损 5% 和止损 10% 的风险差一倍；固定权重会让“看起来一样”的仓位实际风险完全不同。

## 9. 推送与运行时序

### 9.1 收盘 16:20

```
1. 读取账户/状态/昨日计划
2. 昨日计划在今日开盘执行（条件单）
3. 今日收盘更新市场状态
4. 结算持仓（L6 优先级）
5. 收盘盯市、熔断检查
6. 生成明日计划
7. 写 reports/YYYY-MM-DD.md + PushPlus
```

### 9.2 盘前 09:15

```
1. 读取昨收生成的 plan.json
2. 输出：今日可买（gap 区间、止损、目标仓位）+ 持仓卖出关注
3. 无候选则推一条短心跳，证明“系统活着、今天不做”
```

### 9.3 推送规则

| 场景 | 是否推送 |
|---|---|
| 收盘 | 总是推（`push.close_always`） |
| 盘前有候选 | 推完整清单 |
| 盘前无候选 | 推短心跳（可关） |
| 非交易日/计划日期不匹配 | 不推 |
| 运行失败 | 推 traceback 尾部，不静默失败 |

Token 优先从 `PUSHPLUS_TOKEN` 环境变量读；也支持 YAML `runtime.push.tokens` 或复用同机其他模拟盘的 token。
**不要把 token 写进仓库。**

### 9.4 每 5 次收盘推送复盘一次

复盘由 `deploy/regular_paper/review.py` 自动完成，计数规则：

- **只计收盘日报推送成功**；09:15 盘前心跳不计入。否则一天两次推送，2.5 天就复盘一次，样本太少。
- 每 5 次收盘推送 → 生成 `reports/review_YYYY-MM-DD.md`，并再推一条复盘消息。
- 复盘读取账户、逐笔、状态历史、最新计划，输出：
  - 绩效、分形态/退出原因/入场状态统计；
  - 市场状态分布、过滤摘要、推送计数；
  - 25 个第一线参数逐项“保持/观察/降档/暂停”决策；
  - 下期要盯什么。
- **复盘只给建议，不自动改 YAML。** 已平仓样本 <30 笔时，默认结论是“样本不足，不调整”。
- 手动补跑：`python3 review.py --force`；只看不推：`python3 review.py --force --no-push`。

### 9.5 每日复盘（并入收盘日报）

每份收盘日报末尾固定有 **「今日复盘」** 段，回答四件事：

1. 昨日计划执行了多少、哪些未成交/跳过；
2. 今日持仓涨跌与账户盈亏；
3. 运行体检：盘前/收盘推送是否齐全、指数日期、净值记录是否缺交易日；
4. 明日关注什么。

它不额外推送，避免一天三条消息；异常会在报告里用 `⚠️` 直接标出。

### 9.6 收盘后体检（watchdog，17:10）

`watchdog.py` 独立于主流程再查一次“两次推送是否真的发生”：

- 收盘日报缺失且当天尚未结算 → 自动补跑一次 `run_daily.py`（带 flock）；
- 已结算但推送未记 → 只告警，不重跑，避免重复成交；
- 盘前缺失 → 无法补发，只告警并提示检查 09:15 的 cron 行；
- 正常日不推送；异常按“日期 + 告警码”去重（`state/watchdog.json`）。

> 复盘和体检都只描述“发生了什么、有没有按纪律执行”，不预测行情、不自动改参数。

## 10. 参数标准：怎么让“以后能改”

### 10.1 命名

```
模块.对象.指标
timing.cap_trend
selection.pit_max_depth
entry.size_mult_deep_pit
holding.washout_vol
exit.volume_dump_pct
portfolio.risk_per_trade
```

代码只通过这个 id 读取，不在代码里写 `0.12`、`0.9` 这种魔法数字。

### 10.2 每个参数的元数据

```yaml
selection.pit_max_depth:
  value: 0.35          # 默认值
  unit: pct            # pct/x/day/score/count/yuan/frac/bool
  range: [0.22, 0.50]  # 允许手工调整的区间；越界 loader 拒绝启动
  step: 0.01
  tunable: true        # false = 结构/执行假设，不许改
  sensitivity: high    # high/medium/low，改之前先看
  group: selection
  aphorism: "买坑"
  note: "超过这个跌幅更像趋势破坏，不是洗盘。"
```

### 10.3 三个风险档

| 档位 | 用途 | 关键覆盖 |
|---|---|---|
| `defensive` | 市场不确定/个人风险承受低 | 单笔风险 0.8%、单票 22%、TREND 仓 70%、最低分 65 |
| `balanced` | 默认 | 单笔风险 1.25%、单票 28%、TREND 仓 90% |
| `offensive` | 市场趋势明确/风险承受高 | 单笔风险 1.8%、单票 32%、TREND 仓 100%、最低分 55 |

切换：`python3 run_daily.py --profile defensive`，或用环境变量 `REGULAR_PROFILE`。
**同一时间只用一个档位，不要按当天心情切换。**

### 10.4 第一线参数

参数表 113 个，可调 62 个，但真正建议动的只有 25 个（见参数手册 §2）：

- 择时：冷/温/热阈值、CRASH 判定、TREND/HOT 仓位上限
- 选股：坑深上下限、坑内量比、深坑阈值、竖的阈值、最低分
- 买入：高开上限、止损、深坑倍数
- 持有/卖出：洗盘量比、连续大阳天数、移动止盈回撤、放量急跌量比
- 组合：单笔风险、单票上限

### 10.5 调参纪律（比参数本身重要）

1. **每季度最多改 1 个参数**，并写下“改前/改后假设 + 预期影响”。
2. **回撤期禁止调参**。先判断是规则失效还是风格不适；前者停用，后者降仓。
3. **至少 30 笔同状态样本**才允许根据胜率调参；样本不足时只记录，不行动。
4. **改完先跑 `selftest.py` 和 `--demo`**，确认八条口诀没有反向。
5. **参数预算要诚实：** 62 个可调 × 30 笔 = 1860 笔样本；按每年 60–100 笔，需要 19–31 年。
   这就是为什么只能动第一线，且一次只动一个。**大部分参数应该长期冻结。**

## 11. 与打板盘的关系

| 复用 | 改造 |
|---|---|
| L0 可交易性过滤 | 票池从涨停池换成全市场流动性池 |
| L1 状态机 + 仓位上限 | 情绪因子换成指数趋势/宽度/量能 |
| T+1 开盘条件单 | gap 区间从“打板确认”换成“不追高” |
| 硬止损/熔断/成本模型 | 仓位从固定权重换成风险预算 |
| PushPlus 日报/盘前 | 增加“口诀执行”归因段 |
| Markdown 报告/状态查询 | 参数指纹、温度分解、形态统计 |

**没有复用**的是打板的核心：连板身位、封单质量、主线题材、打板成交概率。
常规版不需要这些，也不应该假装需要。

## 12. 验证与已知限制

### 12.1 已验证

`deploy/regular_paper/selftest.py` 用合成行情覆盖 26 个场景，全部通过：

- 横盘 + 连续小涨 → 候选
- 深坑 + 趋势未坏 → 候选，风险预算放大
- 5 日 +25% 的竖 → 排除
- 无量急跌 → 持仓不卖
- 放量急跌 → 清仓
- 连续大涨 → 清仓/减半
- 冲高回落 → 减半
- 市场过热 → 停止开仓；市场急跌 → 仓位 0
- T+1 → 当日买入不可卖
- 参数越界/交叉矛盾 → 拒绝启动
- 全流程 → 生成日报与明日计划

### 12.2 已知限制

| # | 限制 | 影响 | 处置 |
|---|---|---|---|
| O1 | “开盘半小时猛拉不封板”没有分时数据 | 只能用日线长上影代理 | 报告明确标注；有分时后再升级 |
| O2 | 行业字段可能缺失 | 同行业上限失效 | 缺失记为“未分类”，报告写明 |
| O3 | 情绪/宽度只有扫描池样本 | 宽度是近似值 | 报告写 `n=...`，不伪装成全市场 |
| O4 | 没有历史回测 | 不知道长期收益 | 先跑 3 个月影子盘，只记录不下单 |
| O5 | 收盘信号按收盘价成交 | 卖出价略乐观 | 统一假设；实盘用次日开盘会更保守 |
| O6 | 首次拉取 300 只日线较慢 | 2–5 分钟 | 缓存；失败重试；不静默失败 |
| O7 | 东财收盘后断连/日线延迟 | 16:20 可能拿不到当日指数/个股 | 指数退腾讯、快照退新浪批量、历史退新浪、当日 K 线用快照补 |

### 12.3 影子盘要盯的四个数

| 指标 | 门槛 | 说明 |
|---|---|---|
| 单笔毛收益 | ≥ +0.35% | 覆盖双边摩擦后的保本线 |
| 单笔摩擦 | ≤ 0.20% | 滑点 + 佣金 + 印花税 |
| 年交易笔数 | ≤ 100 | 常规波段不应高周转 |
| 最大回撤 | ≤ 12% | 触发停止线就停，不改规则 |

> 如果 3 个月后单笔毛收益 < 0.35%，不要调参救它；先判断这套“横/坑/小涨”是否根本没有边际。

## 附：一句话总结

> **打板盘赚的是“情绪 + 身位”的钱，常规版赚的是“位置 + 量价”的钱。**
> 两者的共同点不是买什么，而是：**先门控、再选股、买入即定止损、卖出按优先级、参数有纪律。**
